# Генератор тестовых данных

[English](README.md) | [Русский](README.ru.md)

Терминальная программа для Windows, которая создаёт JSON с тестовыми данными по схеме, введённой на экране. Исходники можно собрать с помощью Go.

## Скачать и запустить

Открой [последний релиз](https://github.com/vexxy32/test-data-generator/releases/latest), скачай `test-data-generator-windows.zip`, распакуй архив и запусти `TestDataGenerator.exe`. Устанавливать Go не нужно.

Программа создаёт папку `output` в текущей рабочей папке и показывает полный путь к каждому JSON-файлу. При запуске распакованного `.exe` из Проводника эта папка обычно находится рядом с ним.

## Быстрый старт

1. Введи имя и тип поля, затем нажми `+`, чтобы добавить его в схему. Для имён вроде `name` и `cities` тип `string` выбирается автоматически.
2. Укажи количество записей и имя файла. Оставь Seed пустым для нового случайного значения или введи его для повторения результата.
3. Нажми `Ctrl+P` для предпросмотра максимум трёх записей, затем `Enter` для сохранения всего JSON. Если сразу нажать `Enter`, первое нажатие подготовит предпросмотр, второе сохранит файл.

После сохранения программа покажет seed и откроет папку с результатом.

## Возможности

- Генерация полей `integer`, `float`, `string` и `boolean`.
- Настройка числовых диапазонов, длины обычных строк и точности `float` от 0 до 6 цифр после запятой. Пустые границы означают `0..100` для чисел и `1..20` для обычных строк.
- Автоматическое распознавание имён полей: `name`, `email`, `city`, `country`, `company` и других. Для них программа сама выбирает `string` и берёт значение из встроенных списков.
- Связанные значения `name`, `surname` и `email` в одной записи: почта составляется из сгенерированных имени и фамилии.
- Флаг **«Пустое значение»** у каждого поля. В одной автоматически выбранной записи строковые поля с флагом получают `""`, а `integer`, `float` и `boolean` — `null`. Все поля с флагом меняются в одной записи; она может не попасть в первые три записи предпросмотра.
- Автоматическое поле `_test_id` у каждой записи, чтобы проблемные входные данные было легко найти в JSON.
- Seed для воспроизводимой генерации: один seed, схема, порядок полей и количество записей создают одинаковые данные.
- Предпросмотр первых трёх записей. При сохранении в файл попадут именно показанные данные.
- Сохранение и загрузка именных JSON-шаблонов со схемой, количеством записей, именем выходного файла и флагами. Seed в шаблоне не хранится.
- Генерация и запись форматированного JSON по одной записи, без хранения всего набора в памяти. Текущий предел интерфейса — 100 000 000 записей; большие файлы требуют времени и места на диске, во время записи интерфейс ждёт завершения.
- Проверка имени поля, диапазонов, количества записей и длины обычных строк.
- Выбор имени JSON-файла; существующие файлы не перезаписываются, а получают суффикс `_2`, `_3` и так далее.
- Открытие папки с результатом после сохранения.
- `Ctrl+N` начинает новый набор данных без перезапуска программы.

Программа создаёт записи с данными, а не исходный код Go-тестов.

## Запуск из исходников

Установи версию Go из `go.mod`, затем выполни в папке проекта:

```powershell
go run ./cmd/test-data-generator
```

## Сборка для Windows

```powershell
go build -o TestDataGenerator.exe ./cmd/test-data-generator
```

После запуска `TestDataGenerator.exe` папка `output` создастся в текущей рабочей папке.

## Создание ZIP-архива для релиза

В папке проекта выполни:

```powershell
.\scripts\build-release.ps1
```

Скрипт запускает тесты, собирает программу и создаёт `release/test-data-generator-windows.zip`. Для новой версии нужно обновить `VERSION` и отправить изменения в `main`; GitHub Actions сам соберёт ZIP и опубликует релиз.

## Настройки полей и автоматические строки

Для этих имён программа сама выбирает тип `string` и не спрашивает диапазон длины: `name`, `surname`, `email`, `city`, `country`, `company`, `department`, `job_title`, `street_address`, `phone_number`, `user_role`, `status`, `color`, `currency`, `language` и `content_title`. Также поддерживаются варианты во множественном числе и с нижним подчёркиванием, например `cities` и `job_titles`.

Другие строковые поля заполняются случайным текстом заданной длины. Поле `boolean` получает `true` или `false`. Блок **«ФЛАГИ ПОЛЯ»** относится к полю, которое сейчас добавляется или редактируется: выбери «Пустое значение», нажми пробел или `Enter`, чтобы переключить `[нет]` на `[да]`, затем нажми `+` для сохранения поля. В списке схемы такое поле помечено `[пустые]`.

Пустые значения создаются намеренно для проверки нестандартных случаев. `null` отличается от нуля или `false`, а `""` — от отсутствующего ключа. Само поле в записи остаётся.

## Шаблоны

Введи имя шаблона и нажми `Ctrl+S`: он сохранится как `templates/<имя>.json` в текущей рабочей папке. `Ctrl+L` открывает список; выбери шаблон стрелками и нажми `Enter`. Сохранение под тем же именем заменит прежний шаблон. В шаблоне находятся поля и флаги, количество и имя выходного файла, но нет готовых записей и seed. Проверка шаблонов пока допускает не более 10 000 записей, хотя обычная генерация позволяет больше.

## Управление

- `Tab`/`Shift+Tab`, `↑` или `↓`: переход между элементами формы; в списке схемы `↑` и `↓` выбирают поле.
- Пробел или `Enter` на строке «Пустое значение»: переключить флаг текущего поля. В остальных местах `Enter` отвечает за предпросмотр и сохранение.
- `+`: добавить новое поле или сохранить отредактированное.
- `E` в списке схемы: редактировать выбранное поле.
- `Delete` в списке схемы: удалить выбранное поле.
- `Ctrl+P` (или `P` в списке схемы): подготовить предпросмотр первых трёх записей.
- `Enter`: сначала подготовить предпросмотр, если его нет, затем при следующем нажатии сохранить полный JSON.
- `Seed`: оставь пустым для нового случайного seed; сохрани или введи seed, чтобы повторить набор данных.
- `Ctrl+S`/`Ctrl+L`: сохранить шаблон или открыть список для загрузки. В списке схемы также работают `S` и `L`.
- `Ctrl+O` (или `O` в списке схемы): открыть папку с результатом после сохранения.
- `Ctrl+N`: начать новый тест без перезапуска программы.
- `Esc`: отменить редактирование поля, закрыть выбор шаблона или выйти.
